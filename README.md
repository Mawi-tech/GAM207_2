# GM207: Introduction to Game Development I

## Overview
This project involved building a 3D game in Unreal Engine across a series of milestones, implementing core gameplay systems such as character animations, collectible pickups, AI-controlled enemies, projectile mechanics, and player respawn logic.

## Approach
I built the game incrementally, milestone by milestone, starting with character movement and animation before layering in interactive systems like pickups, then progressing to AI behavior, projectile mechanics, and respawn handling. Working within Unreal Engine's content and Blueprint systems, I organized assets and logic so each new feature stayed self-contained and easy to test independently.

## Reflection
Building this project milestone by milestone reinforced how valuable it is to get a single system working reliably before adding the next layer of complexity, since gameplay features like AI behavior and respawns depend heavily on the systems built before them. Working with Unreal Engine's tools also deepened my understanding of how character animation, physics, and AI behavior come together to create a responsive, playable game.

## Skills Demonstrated
- Game development in Unreal Engine
Character animation and control
AI behavior, pickups, and respawn systems
Iterative, milestone-based development
